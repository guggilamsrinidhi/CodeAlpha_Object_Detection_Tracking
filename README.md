# 🎯 Object Detection & Tracking

A web-based Object Detection and Tracking application built using **Python, YOLO, OpenCV, and Streamlit**.

The application allows users to upload images or videos and detect objects using the YOLO model. Videos can also be processed for object tracking with tracking IDs.

## 🚀 Live Demo

🔗 https://codealphaobjectdetectiontracking-yqqeqmmm5gdny3rkwf6elb.streamlit.app/

## ✨ Features

- 🖼️ Upload images for object detection
- 🎥 Upload videos for object detection and tracking
- 🎯 Detect multiple objects using YOLO
- 🔲 Display bounding boxes around detected objects
- 🆔 Track objects across video frames
- 📊 Display confidence scores and object labels
- ⬇️ Download the processed output video
- 🌐 Easy-to-use Streamlit web interface

## 🛠️ Technologies Used

- Python
- YOLO (Ultralytics)
- OpenCV
- Streamlit
- NumPy
- Pillow
- ByteTrack
